# 217
App para manter controle sobre o uso de anticoncepcional

## Requisitos
O app foi criado utilizando expo, react-native e react-native-web
Para iniciar o desenvolvimento é necessário instalar o node.js e o npm

## Instruções de build
Para começar o desenvolvimento, instale os módulos de node do projeto:
```sh
cd 217
npm install
```

Para executar o aplicativo, execute o expo com:
```sh
expo start
```
